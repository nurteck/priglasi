Шаблон папки приглашения. Как использовать — см. главный README.md проекта.
Коротко:

1. Скопируйте всю эту папку в public/invites/ваш-slug (slug — латиницей, через дефис).
2. Вёрстка — в index.html, стиль любой, свои css/js/картинки/шрифты/музыку
   кладите рядом, пути делайте только относительными.
3. ВСЕ ТЕКСТЫ (имена, дата, место, программа и т.д.) — в data.json, а не в
   index.html. В разметке используйте атрибуты data-field="couple.one" и
   т.д. — подробное описание всех возможностей в комментарии в начале
   public/shared/invite-data.js (таймер, списки program/photos, музыка,
   имя и места гостя из ?g=/?n=). Подключите этот скрипт одной строкой:
     <script src="/shared/invite-data.js" defer></script>
   Плавающую кнопку «Назад» (ведёт туда, откуда открыли приглашение — в
   каталог, если своей истории нет) подключите так же:
     <script src="/shared/invite-back.js" defer></script>
4. Заполните meta.json (карточка для каталога/админки):
   - title      — название дизайна в каталоге (например "Golden Arch")
   - category   — одно из: wedding, kyz-uzatuu, sunnot, tushoo, jubilee
   - type       — "catalog" (демо для каталога) или "client" (приглашение
                  конкретного клиента — в каталоге на сайте не показывается)
   - price, oldPrice — цена в сомах (oldPrice необязателен)
   - badges     — любой набор из ["hit", "new"] или вообще без поля
   - order      — порядок в каталоге, меньше = выше
   - author     — кто сделал (ваше имя)
   - hostKey    — длинная случайная строка, секретный ключ для /host/ваш-slug.
                  Никому не публикуется (в публичный каталог не попадает).
   - published  — true, когда готовы показать в каталоге/отдать хозяину
5. Дата тоя отдельно в meta.json не дублируется — она берётся из date в data.json.

Папки, начинающиеся с "_" (как эта), сканер пропускает — их можно использовать
для черновиков.

Приглашение клиенту обычно не создают вручную копированием этой папки, а
клонируют готовый дизайн каталога командой:
  npm run new-invite -- --design исходный-slug --order ID_заказа_в_supabase
Она сама копирует папку дизайна, подставляет данные заказа в data.json,
генерирует новый hostKey и выводит готовую ссылку /host/... для клиента.

После изменений просто запустите `npm run dev` (или `npm run invites`) —
public/invites сканируется автоматически.
